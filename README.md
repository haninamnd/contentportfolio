# Hanin Aimanda — Digital Marketing Portfolio

## Files
- `index.html` — page structure
- `styles.css` — all styling, responsive layout and animation
- `script.js` — interactions, filters, modal case studies and scroll animation
- `data.js` — portfolio content. Edit this file when you want to change text, metrics, links, or media paths.
- `assets/` — put your real screenshots/videos here.

## Add the requested visuals
Use these filenames so the portfolio works immediately:
- `assets/pln-video-1.mp4`
- `assets/pln-video-2.mp4`
- `assets/amala-screenshot.jpg`
- `assets/amala-video.mp4`
- `assets/sanggar-ungu-screenshot.jpg`
- `assets/tiktok-analytics.jpg`
- `assets/tiktok-video.mp4`

If your files have different names, only change the `src` values in `data.js`.

## Important
The portfolio intentionally does NOT invent metrics for PLN or Sanggar Ungu beyond what is supported by the CV.
For internal/project work where reach or engagement data is unavailable, the case study explains the practical value instead.

## Run locally
Open `index.html` in a modern browser. No framework or build tool is required.

For a smoother local experience, you can also use VS Code + Live Server.
